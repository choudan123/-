本目录包含前端代码（React + Vite）。该模板已启用 HMR 并带有基础 ESLint 配置，可根据需要启用 `@vitejs/plugin-react`（Babel）或 `@vitejs/plugin-react-swc`（SWC）。

## 快速开始（本地开发）

### 环境要求
- Node 22+
- npm 

### 安装依赖
```bash
npm install github:https://github.com/choudan123/AIposter.git#frontend

```

### 启动前端

```bash
npm run dev

```
